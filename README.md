# Sipay PrestaShop Plugin — Releases

Official downloadable releases of the **Sipay PrestaShop payment module** — download a ready-to-install `.zip` from the [**Releases**](https://github.com/sipay-tr/presta-plugin-releases/releases/latest) page.

## Download the latest release

1. Open the [**Releases**](https://github.com/sipay-tr/presta-plugin-releases/releases/latest) page.
2. Download the **`sipay-prestashop-plugin-<version>.zip`** file under the latest release.

## Installation

1. In the PrestaShop admin, go to **Modules → Module Manager**.
2. Click **Upload a module** and select the downloaded `.zip` file.
3. PrestaShop uploads and installs the module automatically.
4. Once installed, click **Configure** on the Sipay module and enter your API credentials.

> To update, repeat the same steps with the newest `.zip`; PrestaShop installs it over the existing module.

## Requirements

- PrestaShop **1.7.x** (module compatibility: 1.7 – 1.7.99.99).
- A valid Sipay merchant account and API credentials.

## Security

If you believe you have found a security vulnerability in this plugin, please report it privately to **[infosec@sipay.com.tr](mailto:infosec@sipay.com.tr)**. Please do not open a public GitHub issue, pull request, or discussion for security reports.

To help us triage your report quickly, please include:

- the plugin version and platform version affected,
- a description of the issue and its potential impact,
- steps to reproduce or a proof of concept, if available.

We will acknowledge your report, investigate it, and keep you informed of our progress. Please give us reasonable time to release a fix before disclosing the issue publicly. We always recommend using the latest release, which includes the most recent security updates.
